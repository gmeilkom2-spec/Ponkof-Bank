# ПОНЬКОФ — Firebase + GitHub Pages

Готовый демонстрационный личный кабинет: регистрация, вход, баланс, виртуальная карта, сохранение карты в Firestore, история начислений и панель администратора.

## 1. Создай Firebase

1. Открой Firebase Console.
2. Создай проект.
3. Добавь Web App.
4. Скопируй `firebaseConfig`.
5. В Authentication включи **Email/Password**.
6. Создай Firestore Database.
7. Вставь содержимое `firestore.rules` в Rules.
8. В `app.js` вставь свой `firebaseConfig`.
9. В `app.js` и `firestore.rules` замени `YOUR_ADMIN_EMAIL@example.com` на email администратора.

## 2. GitHub Pages

Создай репозиторий, загрузи все файлы из этой папки и включи GitHub Pages для ветки `main` / папки `/`.

GitHub Pages публикует статические HTML/CSS/JS-файлы прямо из репозитория.

## 3. Что умеет сайт

- Регистрация и вход через Firebase Authentication.
- Личный баланс.
- Открытие виртуальной карты.
- Номер карты, срок и CVV сохраняются в Firestore.
- История начислений.
- Администратор может найти клиента по email и начислить ему сумму.
- Баланс изменяется через серверные правила Firestore, а не только визуально в браузере.

## Важно

Это учебный/игровой банковский интерфейс с виртуальной валютой. Не используй его для хранения настоящих банковских реквизитов, реальных платежей или данных карт.

Для реального финансового продукта нужна серверная логика, аудит, защита персональных данных, соответствие требованиям платёжных систем и безопасное хранение секретов.

Firebase config для Web App можно публиковать в клиентском JavaScript, но права доступа должны защищаться Firestore Security Rules.
